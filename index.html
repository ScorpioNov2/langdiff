Langdiff - Usage & Formatting Guide

The custom rendering engine operates on a strict, predictable rule: Every row beginning with + or - will have the prefix symbol AND EXACTLY ONE white space immediately following it stripped away. Any subsequent indentation spaces located after that first stripped space are treated as intentional data and will be preserved exactly as written.

📝 SYNTAX RULES
Prefix Row Appearance Ideal Use Case
- Red Background Original Language (e.g., Vietnamese) / Old Code
+ Green Background Target Language (e.g., English) / Updated Code
None Standard White Row Context Dividers / Shared Descriptive Explanations
📐 FORMATTING EXAMPLES
❌ Incorrect Formatting (Misunderstanding the Strip Rule)

If you write prefixes directly stuck to the text without a following space:

-def compute_total():
+def compute_total():
-    print("Old code")
+    print("New code")
Why this breaks: On line 4, the row starts with + followed by 4 indentation spaces. The engine catches the + and swallows the 1st space, leaving only 3 leading spaces on your screen. This completely breaks Python's syntax tree!
✅ Correct Formatting (Intentionally Planning for the Strip Rule)

To make your content match up beautifully, you must explicitly type exactly ONE single space directly behind every prefix:

- def compute_total():
+ def compute_total():
-     print("Old code")
+     print("New code")
Why this works flawlessly: On line 4, the row is written with a +, a single space, and then the 4-space code indent (totaling 5 spaces). The engine strips the + (symbol + 1st space). The remaining string is rendered with exactly 4 spaces of indentation!
💡 GENERAL TEXT RULE (LANGUAGE LEARNING)

The same logic applies to text paragraphs. Always put exactly one space after the symbol so your sentences sit flush against the margin:

- Tôi đang sử dụng ứng dụng Langdiff.
+ I am using the Langdiff application.
